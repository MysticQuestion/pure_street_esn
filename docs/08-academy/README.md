# STREETS Academy

Independent civic education for Oakland waste literacy.

**Live product:** [https://oaklandstreets.live/academy](https://oaklandstreets.live/academy)

STREETS Academy complements Oakland Recycles and OAK311. It does not replace them. It is not a City of Oakland system, not a hauler training program, and is not represented as a municipal credential.

## In this directory

- [STREETS-WR101.md](./STREETS-WR101.md) — flagship course curriculum
- [course-brief.md](./course-brief.md) — original course design brief

Implementation (interactive modules, sorting labs, 98th Avenue simulation, certificate) lives in:

- Live site: `MysticQuestion/sentinel-civic-heart` at `/academy`
- Source snapshot in this monorepo: `apps/academy/`

Progress is stored on the learner’s device. No account is required for the pilot.
